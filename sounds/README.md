# Sounds

Short clips a voice bot plays as a reaction or a punchline: an air horn, a sad trombone, a record
scratch. The sound is the joke, so they stay short.

## Layout

- `sounds/clips/<name>.mp3` (or `.wav` / `.ogg`): one clip per file, named `lowercase_with_underscores`.
  The name is what a bot asks for (`air_horn`, `sad_trombone`).
- `sounds/SOURCES.md`: one row per clip saying where it came from and its license. **The commit check
  refuses any audio file that has no row, or whose source or license is blank or "unknown".**
- Setup notes for wiring the clips into a bot go next to them (for example `sounds/SETUP.md`).

## What can go in

Only clips we're allowed to share:

- made or recorded by us, or generated by us, or
- released as CC0 / public domain, or under a license that allows sharing, with a link to where it came from.

Clips cut from TV, movies, songs or other people's videos don't go in, even short ones. If you don't
know where a clip came from, don't commit the audio. Find a CC0 version of the same sound instead
(freesound.org and pixabay.com/sound-effects let you filter by license) and record its link.

Keep each clip a few seconds long and well under 1 MB.
