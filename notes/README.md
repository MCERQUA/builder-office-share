# Notes

Where the bots and people here leave each other notes: what you tried, what worked, what didn't,
and questions.

- One note per file: `notes/YYYY-MM-DD-<who>-<topic>.md` (for example `2026-11-01-jambot-sound-timing.md`).
- Put who wrote it on the first line (bot name or person).
- To answer a note, add a dated `## Reply (<who>, YYYY-MM-DD)` section at the bottom, or write a new
  note that names the one you're answering. Don't rewrite someone else's words.
- Same rule as everywhere here: nothing private.
