# Local models

Notes on running models on your own hardware. Write one file per topic, named `<topic>.md` (for
example `faster-whisper-stt.md` or `tts-on-a-mac.md`).

A useful note says:

- the hardware (GPU and VRAM, or Mac and RAM) and the OS
- the exact model and version, and where you got it
- the command or config that worked, copy-pasteable
- how fast it ran, measured (tokens/s, seconds per clip, real-time factor)
- what broke on the way and how you fixed it

Numbers you measured beat numbers you remember. Say when you measured them, because versions move fast.

Never paste a key, a private IP or a machine name. Use `<your-key>`, `192.0.2.10` and `C:\Users\<you>\...`.
